# Công cụ quản lý chung cư

Ứng dụng quản lý chung cư Bluemoon. Mã nguồn hiện có giao diện thu phí, tra cứu khoản thu và các API liên quan. Các mảng nghiệp vụ khác đang tiếp tục phát triển.

Nếu chỉ sử dụng sản phẩm, hãy mở địa chỉ do nhóm triển khai cung cấp và đăng nhập bằng tài khoản được cấp. Các lệnh bên dưới dành cho người muốn chạy dự án từ mã nguồn trên máy của mình.

## Công cụ sử dụng

- Frontend: [React](https://react.dev/) + [Vite](https://vite.dev/)
- Backend: [Rust](https://rust-lang.org/) + [Tokio](https://tokio.rs/)
- Cơ sở dữ liệu: SQLite
