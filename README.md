# Công cụ quản lý chung cư

Ứng dụng fullstack quản lý toàn diện một khu chung cư, các tính năng bao gồm
- Quản lý nhân khẩu
- Quản lý căn hộ
- Quản lý thu phí
- Quản lý phương tiện

## Công cụ sử dụng

- Frontend: [React](react.dev)
- Backend: [Rust](https://rust-lang.org/) + [Tokio](https://tokio.rs/)
- Cơ sở dữ liệu: SQLite
